# Editor Contract（予定）

すべての編集コンポーネントが満たす共通契約の所有場所。

予定: interface.d.ts / editor_registry.js / editor_factory.js / tests/（名称・形式は案）。
値設定・取得、ライフサイクル、変更通知、状態制御等の共通契約を扱う。
コンポーネント固有の機能やアプリの保存処理は置かない。
FieldDefから解決された入力制約や検証バリエーションとの接続は将来検討する。

共通契約テストは、コンポーネント固有テストとは独立して再利用できるようにする。
現時点では配置のみ。実行コード・確定済みインターフェースはまだ存在しない。
