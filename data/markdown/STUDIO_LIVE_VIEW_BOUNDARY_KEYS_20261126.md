# Live View Design — 境界操作 (2026-11-26)

## 操作契約
- 基本情報／詳細Editorの隣接項目間。前の項目の右端にマウスを合わせて青い縦線を表示する。改行ボタンは撤去。左ドラッグは従来の幅調整。
- Enter: 次の表示項目の直前に明示的改行を追加。Delete/Backspace: 明示的改行のみ解除。
- 青い縦線を右クリック: 次の表示項目の直前に横境界線を追加。境界線自体が行を分ける。既存の明示的改行は変更しない。
- 横境界線にマウスを合わせ青くなった状態でDelete/Backspace: 境界線のみ削除。明示的改行は維持。
- 幅固定のradio/booleanなどにはレイアウト専用の右端ハンドルを追加。幅の責務は変更しない。
- 正確なハンドルのホバー時のみキー操作を横取りする。本文にフォーカスが残っていてもホバーが明示的な操作対象になる。外れれば通常操作。IME変換中、修飾キー付き、リサイズ中、他のダイアログ表示中は対象外。消えた境界に対するキー長押しのリピートはキー解放まで消費する。
- 次の項目が存在しない場合はレイアウト変更しない。FieldSet内の操作には対応するが、FieldSetやFooterをまたぐ挿入は対象外。Search/Grid/子グリッドは対象外。

## ViewDef
`layout.separatorBefore: true/false` を追加。`layout.breakBefore` / `layout.height` / `width` と独立。既存のレイアウト保存を利用する。Data JSON・本文の未保存入力は変更しない。デザインモードは追加しない。権限機能は将来課題。
